## 🧪 Research Approach

I value **reproducibility over impressive-looking claims**. My research workflow aims to make the question, setup, baselines, evaluation metrics, limitations, and next steps clear — including negative or inconclusive findings.

When a result is promising, I want the evidence to show *why*. When it is not, that is useful information too.
